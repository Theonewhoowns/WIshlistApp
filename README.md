# WishlistApp

Java-приложение с графическим интерфейсом для ведения списков желаний и подбора подарков. Использует Java 8, JavaFX 8 и JDBC. Поддерживает PostgreSQL и Microsoft SQL Server. База данных содержит восемь связанных таблиц.

## Возможности

- Создание списков желаний, добавление и редактирование подарков, отметка о покупке, расчёт оставшейся стоимости.
- Ведение получателей подарков с указанием возраста и интересов.
- Подбор подарков из каталога по получателю, бюджету и поводу.
- Регистрация и вход. Пользователь работает со своими списками и получателями, администратор дополнительно управляет каталогом и справочником интересов.

## Требования

- JDK 8 с JavaFX 8. Команды `java`, `javac` и `jar` должны быть доступны в терминале. Если задан `JAVA_HOME`, он должен указывать на установленный JDK 8.
- Установленная PostgreSQL или Microsoft SQL Server с доступом по TCP.
- Git для клонирования проекта. JDBC-драйверы включены в папку `lib`; Maven для сборки не требуется.

## Получение проекта

```sh
git clone https://github.com/Theonewhoowns/WIshlistApp.git
cd WIshlistApp
```

## Подготовка базы данных

1. Подключитесь к СУБД через DBeaver или SQL Server Management Studio. Для PostgreSQL можно использовать базу `postgres`; для SQL Server создайте пользовательскую базу `WishlistApp`.
2. В выбранной базе выполните по порядку `01_schema.sql` и `02_seed.sql` из папки `database/PostgreSQL` или `database/SQLServer`. Используйте учётную запись с правами на создание объектов. Скрипты создают схему `wishlistApp`, заполняют таблицы тестовыми данными и проверяют ограничения.
3. Для полного каталога подарков дополнительно выполните `database/06_import_original_catalog_postgresql.sql` или `database/06_import_original_catalog_sqlserver.sql` для выбранной СУБД.

`01_schema.sql` сразу создаёт структуру, соответствующую НФБК.  `04_queries.sql` содержит примеры запросов. Повторно создавать и заполнять уже подготовленную базу не требуется.

## Настройка подключения

Скопируйте один из шаблонов в файл `config/db.properties`:

- PostgreSQL — `config/postgresql.example.properties`;
- SQL Server — `config/sqlserver.example.properties`.

Укажите в копии адрес сервера, порт и имя базы в `db.url`, логин СУБД в `db.user` и пароль в `db.password`. Значения `db.type` и `db.schema` оставьте как в выбранном шаблоне. Для SQL Server используется SQL-аутентификация и настроенный TCP-порт.

Учётная запись подключения должна иметь права на чтение и изменение данных схемы `wishlistApp` и получение новых идентификаторов. Пароль СУБД отличается от пароля пользователя приложения. Файлы с личными настройками подключения исключены из Git.

Если база работает на другом компьютере, укажите его адрес вместо `localhost`. В виртуальной машине `localhost` обозначает саму виртуальную машину.

## Сборка и запуск

Все команды выполняются из корня проекта. После клонирования сначала нужна сборка: папка `target` не хранится в Git.

**Windows, PowerShell:**

```powershell
.\build.bat
.\run.bat
```

**Linux, терминал в графической сессии:**

```sh
sh build.sh
sh run.sh
```

После успешной сборки для следующих запусков достаточно `run.bat` или `sh run.sh`. В окне приложения выберите файл настроек, нажмите «Подключиться» и войдите.
